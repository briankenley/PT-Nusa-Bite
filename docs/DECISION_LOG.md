# Decision Log — PT NusaBite Cepat Saji

Format mengikuti **Format wajib Decision Defense** (Bagian 10 handout). Setiap keputusan punya ID `D-xx`, dirujuk dari kode (`src/policies.js`) dan dari [TEST_RESULTS.md](TEST_RESULTS.md).

> Status: **draf yang disiapkan bersama AI.** Pemegang keputusan (A) untuk Decision Log adalah **M1 (Product Owner)** sesuai RACI. Tim wajib meninjau, menyetujui, atau mengubah setiap baris sebelum presentasi. Bila sebuah keputusan dibalik, ubah konstanta terkait di `src/policies.js` lalu jalankan ulang `npm test` dan `npm run evidence`.
